# 🎓 Student Management System

A simple Student Management System built using Python that demonstrates Object-Oriented Programming (OOP), file handling, and CRUD operations.

## 🚀 Features

- Add a student
- Display all students
- Search a student by ID
- Update student details
- Remove a student
- Save student records to a text file
- Load student records from a text file
- Exception handling for missing files

## 🛠 Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- File Handling
- Exception Handling

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/student-management-system.git
```

2. Navigate to the project folder

```bash
cd student-management-system
```

3. Run the program

```bash
python main.py
```
